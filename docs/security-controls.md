# Security Controls

This document summarizes the security concepts practiced in the lab.

## Identity and access

- Role-Based Access Control (RBAC)
- Security group-based permissions
- Separate administrative and standard-user access
- User provisioning and deprovisioning workflows
- Least-privilege account management

## Endpoint security

- Microsoft Intune enrollment
- Compliance policies
- Security-focused endpoint configuration
- Software deployment and patch-management concepts
- Standardized workstation configuration

## Windows security administration

- Group Policy management
- Password and account policy concepts
- Active Directory security groups
- Administrative privilege review
- Centralized identity management

## Network services

- DNS configuration and troubleshooting
- DHCP concepts
- TCP/IP connectivity validation

## Cloud concepts

- AWS EC2 infrastructure
- AWS IAM fundamentals
- Security group concepts

## Security principle

The lab is designed around minimizing unnecessary administrative access, centralizing policy enforcement, and maintaining consistent endpoint configurations.
